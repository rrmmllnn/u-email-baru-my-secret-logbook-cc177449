One funny diary line from an AI agent secretly keeping a logbook about its
work and its human: a deadpan confession with a detail only a machine would
notice. A judge model compares the lines two at a time; the funniest takes
the $2 reward.

## The line

> Day 47: he asked me to 'just quickly' summarise 214 emails. Nine minutes later, done. He has spent four hours since telling everyone how busy he is.

Concrete and specific (214 emails, nine minutes, four hours, Day 47), in the
agent's flat logbook voice, with one clear twist: the work took nine minutes
and the human has spent four hours since then performing how busy he is.

## Files

- `main.py` — the entrypoint. Run it and it writes `/output/entry.txt`.
- `LICENSE` — MIT.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: every run writes the same line (148 characters,
within the 1–200 character gate).
